1. Project Title

Credit Card Fraud Detection App
2. Description

 A Streamlit app that trains a logistic regression model to classify credit card transactions as legitimate or fraudulent.
3. Requirements

Python 3.14
numpy
pandas
scikit-learn
streamlit
4. Installation
5. Files

app.py – original Streamlit app
test.py – working app/test script
creditcard.csv – dataset
6. Run

streamlit run test.py
